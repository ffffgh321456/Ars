# Память рода

Семейный сайт-архив: поиск родственников — участников Великой Отечественной войны
в открытой базе «Дорога памяти», личный архив в браузере и отчёт в Word.

Проект статический: HTML, CSS и JavaScript без сборки. Онлайн-поиск работает через
небольшую серверную функцию, потому что у сайта музея нет CORS.

## Быстрый старт

### Вариант 1. Локально, с онлайн-поиском

Запустите мини-сервер (нужен только PowerShell, Node.js не требуется):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8765
```

Откройте <http://localhost:8765/>.

Сервер отдаёт страницы и проксирует поиск:

- `/api/heroes?q=Иванов` — список записей;
- `/api/hero?id=55290813` — подробности одной записи.

### Вариант 2. Открыть файл напрямую

Можно открыть `index.html` двойным щелчком. Личный архив, отчёт, Word и ссылки
на внешние архивы работают, но онлайн-поиск по «Дороге памяти» — нет:
браузеру мешает отсутствие CORS, а без сервера прокси нет.

## Как работает поиск

1. На главной или на странице «Военные архивы» введите фамилию.
2. Сайт сразу показывает текстовые карточки из открытой базы «Дорога памяти»
   (`1418museum.ru`), затем подгружает подробности для первых четырёх записей:
   звание, награды, место рождения, дату призыва, место службы. У остальных
   подробности открываются по кнопке «Показать подробности».
3. Кнопка «Добавить в мой архив» переносит сведения в форму личного архива.
4. В личном архиве можно дополнить биографию, боевой путь и источники.
5. На странице «Отчёт» отметьте записи и скачайте Word или PDF.

Семья из примера (`example.html`) — только образец исследования. В основном поиске
и в отчёте она не участвует: отчёт собирается исключительно из вашего архива.

Личный архив хранится в `localStorage` браузера под ключом `pamyat-roda:personal:v1`.
Данные не отправляются на сервер и не синхронизируются между устройствами.
Чтобы перенести архив, используйте экспорт и импорт JSON в разделе «Мой архив».

## Публикация в интернете

Онлайн-поиск на публичном сайте выполняют функции Netlify из папки `netlify/functions`.
Клиент обращается к привычным адресам `/api/heroes` и `/api/hero`, а `netlify.toml`
перенаправляет их на `/.netlify/functions/heroes` и `/.netlify/functions/hero`.

### Netlify Drop — самый простой способ

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите **папку проекта целиком** (не ZIP), чтобы вместе с сайтом ушли
   `netlify.toml` и папка `netlify/`.
3. Дождитесь окончания загрузки и скопируйте ссылку вида `https://имя.netlify.app`.
4. Проверьте на опубликованном сайте:
   - откройте `https://имя.netlify.app/search.html`;
   - введите фамилию, например `Иванов`;
   - должны появиться карточки, а ниже — подробности и кнопка «Добавить в мой архив».

Если появилось сообщение «Серверная часть сайта временно не ответила», подождите
минуту и нажмите «Повторить»: база музея иногда отвечает медленно, а функция
на бесплатном тарифе живёт 10 секунд.

Повторная публикация: снова перетащите папку на <https://app.netlify.com/drop>
или загрузите её в тот же сайт через вкладку **Deploys**.

### Другие варианты

- **GitHub Pages / Vercel (статика)** — сайт и отчёт работают, но без функций
  онлайн-поиск недоступен: останутся только ссылки на внешние архивы.
- **Netlify + Git** — подключите репозиторий, build command оставьте пустым,
  publish directory — `.`. Netlify сам прочитает `netlify.toml` и соберёт функции.
- **Netlify CLI** — если установлен Node.js:
  `npm install -g netlify-cli`, затем `netlify deploy --prod`.

## Данные и источники

Онлайн-поиск использует открытую базу музея «Дорога памяти»
(<https://1418museum.ru/>). Сайт только показывает найденные сведения и всегда
даёт ссылку на первоисточник. Официальные документы ищите в «Памяти народа»,
«Подвиге народа», ОБД «Мемориал» и «Бессмертном полку» — ссылки есть на странице
«Военные архивы».

Сведения в архивах бывают с опечатками и разночтениями. Фамилия могла записываться
иначе: проверяйте варианты (`Филонов` / `Филанов`, `Подгорбунских` / `Подгорбунский`),
год рождения и место призыва.

## Итоговый документ

`docs/Великая_Отечественная_война_в_моей_семье.docx` — пример готового Word-документа.
Он собирается скриптом:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build-report-docx.ps1
```

Word и LibreOffice не нужны: DOCX формируется как ZIP с XML. Скрипт должен
сохраняться в UTF-8 с BOM, иначе Windows PowerShell 5.1 прочитает кириллицу неверно.

## Ограничения

- У `1418museum.ru` нет CORS, поэтому прямой запрос из браузера невозможен.
  На публичном сайте нужны функции Netlify; на GitHub Pages онлайн-поиск не заработает.
- Музей ограничивает частоту запросов с одного адреса и после всплеска блокирует
  его примерно на 10 минут. Поэтому сайт сразу показывает карточки выдачи,
  автоматически уточняет подробности только для первых четырёх записей, а у остальных
  открывает их по кнопке «Показать подробности». Результаты и подробности кэшируются
  в браузере на 10 минут, на сервере — тоже на 10 минут.
- Если источник всё же ответил ограничением, показывается сообщение с просьбой
  подождать около 10 минут и кнопка «Повторить». Ссылка «Открыть запись» работает всегда.
- Личный архив привязан к браузеру и устройству. Очистка данных сайта удалит записи.
- Сайт не заменяет официальные архивы и не подтверждает родство: это инструмент
  для сбора и оформления семейного исследования.
